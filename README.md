# microsoft word

![Bombarded by Words](assets/cover.jpg)
*Words, words, words — the thing every word processor is ultimately for. (Violetta Raine · CC BY)*

People type `microsoft word` into a search box for a handful of reasons, and they are not the same reason. Some want the desktop program. Some want the browser version. Some just want to open a `.docx` someone emailed them and don't care whose logo is on the toolbar. This page is a starting note for all three, plus the inevitable "is there a free one?" question that follows.

## What Word actually is

Microsoft Word is a word processor: a program for writing, formatting, and saving text documents, with the emphasis on *formatting*. The formatting is the whole point. A plain text file can hold the same words, but it can't hold a heading style, a table with borders, a footnote at the bottom of page 3, a comment in the margin, or a tracked change showing that someone deleted your second paragraph. Word stores all of that in its `.docx` format, which is an open, documented container of XML files zipped together — rename any `.docx` to `.zip` and you can look inside.

That last fact matters more than it sounds. It means a `.docx` is not a black box owned by one company; it's a format many programs can read and write. Word is the best-known program that does so, but it is not the only one, and the format outlives any single version of the app.

The lineage runs from the 1983 MS-DOS original through the Windows and Mac versions that dominated offices in the 1990s, to the ribbon interface introduced in Word 2007, to today's continuously updated Microsoft 365 builds and the browser edition. The `.doc` binary format gave way to `.docx` in 2007. If you find a `.doc` file from 1998, modern Word still opens it, usually with a compatibility warning.

## The three ways people actually use it

**Desktop app.** The installed program on Windows or Mac. Full feature set: mail merge, macros, citations, advanced layout, offline editing. This is what most people mean by "Microsoft Word."

**Word for the web.** A browser version at office.com, free with a Microsoft account. It covers the common 90% — typing, basic styles, tables, comments, real-time co-editing — and is genuinely good for collaborative drafting. It is not the full desktop app. Some layout controls, certain field codes, and heavier automation simply aren't there, and documents with complex formatting may look slightly different than they do on the desktop.

**The mobile apps.** iOS and Android versions, fine for reading and light edits, awkward for anything involving precise layout.

## If you don't want to pay, or don't want Word at all

This is the honest part most pages bury. You do not need Microsoft Word to open or create a `.docx`.

- **LibreOffice Writer** — free, open source, desktop, reads and writes `.docx` well. The closest full-featured drop-in.
- **Google Docs** — free in a browser, imports and exports `.docx`, excellent for collaboration. Its native format is its own, so round-t complex documents can shift formatting.
- **Apple Pages** — free on Apple devices, exports to `.docx`.
- **Word for the web** — free with an account, as above.
- **WordPad** — the ancient Windows extra. It opens `.docx` but has almost no formatting tools and has been on its way out for years. Don't build a workflow on it.
- **Plain text editors** — fine for writing, useless for `.docx` formatting.

The practical rule: if you only need to *read* a document, almost anything works. If you need to *preserve* intricate formatting through an edit-and-return cycle, stay in the same program the document was made in. Cross-program round-trips are where layout quietly drifts.

## Gotchas worth knowing before you commit

- **File extensions lie by omission.** A `.docx` that won't open is often a `.doc`, an RTF, or a file someone renamed. Check the actual content, not the name.
- **"Compatibility mode"** in the title bar means the document is using an older feature set. Save As to the current format to unlock newer features, but do it deliberately — it can change layout.
- **Tracked changes and comments travel with the file.** Send a document for review and the reviewer's edits come back inside it. Review them before you accept anything.
- **Fonts are not embedded by default.** A document that looks right on your machine can reflow on someone else's because they lack the font. Use widely available fonts for anything you send out.
- **Autosave is not backup.** Cloud autosave protects against a crash, not against deleting the wrong paragraph an hour ago. Version history does, if the file lives in OneDrive or SharePoint.
- **The web version silently downgrades.** Features it can't handle are often preserved but not editable — you may not notice until you reopen on the desktop.

## Which one to pick

If your work involves heavy formatting, macros, or offline use, install the desktop app. If you're drafting and sharing with other people, the web version is faster to start and free. If you object to the subscription, LibreOffice Writer is the honest answer and it handles `.docx` fine for ordinary documents. And if you just need to read one file, don't install anything — open it in whatever you already have.

The format is the durable part. The program is a choice.
